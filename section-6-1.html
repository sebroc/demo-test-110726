    Section 4.1 Examples and Basic Properties

    Textbook section 6.1.
    🔗
    In Chapter 5, we will work with vectors in \(\mathbb{R}^n\text{.}\) Many results will rely on the fact that vectors in \(\mathbb{R}^n\) can be added and multiplied by scalars in a familiar way. However, vectors in \(\mathbb{R}^n\) is not the only set that has these properties.
    🔗
    Since so many useful sets exhibit the same properties, we will develop a name and theory surrounding these sets with addition and scalar multiplication that “play nice” with each other.
    🔗

    Definition 4.1.1.

    A vector space consists of a nonempty set \(V\) of objects (called vectors) that can be added, that can be multiplied by a real number (called a scalar in this context), and for which certain axioms hold. If \({\mathbf{v}}\) and \({\mathbf{w}}\) are two vectors in \(V\text{,}\) their sum is expressed as \({\mathbf{v}}+{\mathbf{w}}\text{,}\) and the scalar product of \({\mathbf{v}}\) by a real number \(a\) is denoted as \(a{\mathbf{v}}\text{.}\) The following axioms are assumed to hold.
    🔗
    • A1. If \({\mathbf{u}}\) and \({\mathbf{v}}\) are any elements in \(V\text{,}\) then \({\mathbf{u}}+ {\mathbf{v}}\) is in \(V\). In this case, we say \(V\) is closed under vector addition.
      🔗
      🔗
    • A2. \({\mathbf{u}}+ {\mathbf{v}}=\) \({\mathbf{v}}+ {\mathbf{u}}\) for all \({\mathbf{u}}, {\mathbf{v}}\) in \(V\) .
      🔗
      🔗
    • A3. \({\mathbf{u}}+ ({\mathbf{v}}+ {\mathbf{w}}) =\) \(({\mathbf{u}}+ {\mathbf{v}}) + {\mathbf{w}}\) for all \({\mathbf{u}}, {\mathbf{v}}, {\mathbf{w}}\) in \(V\text{.}\)
      🔗
      🔗
    • A4. There exists an element zero in \(V\) such that \({\mathbf{v}}+ {\mathbf{0}}= {\mathbf{0}}+ {\mathbf{v}}=\) \({\mathbf{v}}\) for any \({\mathbf{v}}\in V\text{.}\) The vector \({\mathbf{0}}\) is called the zero vector.
      🔗
      🔗
    • A5. For each \({\mathbf{v}}\) in \(V\) there exists an element \(- {\mathbf{v}}\) in \(V\) such that \({\mathbf{v}}+ (- {\mathbf{v}}) = -{\mathbf{v}}+ {\mathbf{v}}=\) \({\mathbf{0}}\). The vector \(-{\mathbf{v}}\) is called the negative of \({\mathbf{v}}\) or additive inverse of \({\mathbf{v}}\text{.}\)
      🔗
      🔗
    • S1. If \({\mathbf{v}}\) is any element in \(V\) and \(a\) is any real number, then \(a {\mathbf{v}}\) is in \(V\). In this case, we say \(V\) is closed under scalar multiplication.
      🔗
      🔗
    • S2. \(a ({\mathbf{u}}+ {\mathbf{v}}) =\) \(a {\mathbf{u}}+ a {\mathbf{v}}\) for any \({\mathbf{u}}, {\mathbf{v}}\) in \(V\) and any \(a\) in \(\mathbb{R}\text{.}\)
      🔗
      🔗
    • S3. \((a+b) {\mathbf{v}}=\) \(a {\mathbf{v}}+b {\mathbf{v}}\) for any \({\mathbf{v}}\) in \(V\) and any \(a,b\) in \(\mathbb{R}\text{.}\)
      🔗
      🔗
    • S4. \(a (b {\mathbf{v}}) =\) \((a b) {\mathbf{v}}\) for any \({\mathbf{v}}\) in \(V\) and any \(a,b\)in \(\mathbb{R}\text{.}\)
      🔗
      🔗
    • S5. \(1 {\mathbf{v}}=\) \({\mathbf{v}}\) for any \({\mathbf{v}}\) in \(V\text{.}\)
      🔗
      🔗
    🔗
    The operation \({\mathbf{v}}+{\mathbf{w}}\) is called vector addition and the operation \(a{\mathbf{v}}\) is called scalar multiplication.
    🔗
    🔗

    Note 4.1.2.

    When using a “non-standard” vector addition and/or scalar multiplication, we will denote vector addition as \(\oplus\) and scalar multiplication as \(\odot\text{.}\)
    🔗
    🔗

    Note 4.1.3.

    We will often just use the phrase “vector space,” dropping the “real” and assuming our scalars are from the real numbers in this course. However, it is possible to have complex vector spaces, rational vector spaces, etc.! Warning: From now on, “vector” will just mean an element of a vector space, not necessarily a directed line segment.
    🔗
    🔗

    Example 4.1.4.

    The set \(\mathbb{R}^n\) is a real vector space for any natural number \(n\text{.}\) This is the most common “day-to-day” vector space.
    🔗
    🔗

    Example 4.1.5.

    The set of all \(m \times n\) matrices with real entries with matrix addition as addition and scalar multiplication of a matrix by a real number as scalar multiplication is a vector space. We denote this vector space by \(M_{mn}\text{,}\) \(M_{{m \times n}}\text{,}\) or \(\mathbb{R}^{m \times n}\text{.}\) Prove that \(M_{22}\) is closed under addition and scalar multiplication. What is the zero vector in this vector space?
    🔗
    Solution.
    For matrices \(\begin{bmatrix} a & b \\ c & d \end{bmatrix}, \begin{bmatrix} e & f \\ g & h \end{bmatrix} \in M_{22}\text{:}\) Their sum is \(\begin{bmatrix} a+e & b+f \\ c+g & d+h \end{bmatrix} \in M_{22}\) For scalar \(k\text{:}\) \(k\begin{bmatrix} a & b \\ c & d \end{bmatrix} = \begin{bmatrix} ka & kb \\ kc & kd \end{bmatrix} \in M_{22}\) The zero vector is \(\begin{bmatrix} 0 & 0 \\ 0 & 0 \end{bmatrix}\) because: \(\begin{bmatrix} a & b \\ c & d \end{bmatrix} + \begin{bmatrix} 0 & 0 \\ 0 & 0 \end{bmatrix} = \begin{bmatrix} a & b \\ c & d \end{bmatrix}\) for any matrix
    🔗
    🔗
    🔗

    Example 4.1.6.

    (a)

    A polynomial (in \(x\)) is a function expressible as
    🔗
    \begin{equation*} p(x) = \underline{a_0 + a_1x + a_2x^2 + \cdots + a_dx^d} \end{equation*}
    🔗
    where \(a_0, a_1,\ldots, a_d\) are real numbers and \(d\) is a nonnegative integer. If \(a_d \neq 0\text{,}\) we say \(p(x)\) has degree \(d\text{.}\) Let \(P\) be the set of all polynomials, and let \(P_d\) be the set of all polynomials of degree \(\leq d\) together with the zero polynomial \(p(x) = 0\text{,}\) denoted \({\mathbf{0}}\text{.}\)
    🔗
    Using the standard polynomial addition and scalar multiplication for polynomials, \(P\) is a vector space and each \(P_d\) is a vector space.
    🔗
    Let’s walk through the proof that \(\mathbf{P}_2\) (the set of polynomials of degree at most 2) is a vector space.
    🔗
    (A1) If \({\mathbf{u}}\) and \({\mathbf{v}}\) are in \(V\text{,}\) then \({\mathbf{u}}+ {\mathbf{v}}\) is in \(V\text{.}\)
    🔗
    Solution.
    Let \(u(x) = a_0 + a_1x + a_2x^2\) and \(v(x) = b_0 + b_1x + b_2x^2\) be in \(\mathbf{P}_2\text{.}\) Then \(u(x) + v(x) = (a_0 + b_0) + (a_1 + b_1)x + (a_2 + b_2)x^2\text{.}\) Degree is at most 2, so \({\mathbf{u}}+{\mathbf{v}}\in \mathbf{P}_2\)
    🔗
    🔗
    🔗

    (b)

    (A2) \({\mathbf{u}}+ {\mathbf{v}}={\mathbf{v}}+ {\mathbf{u}}\) for all \({\mathbf{u}},{\mathbf{v}}\) in \(V\text{.}\)
    🔗
    Solution.
    \((a_0 + a_1x + a_2x^2) + (b_0 + b_1x + b_2x^2)\) \(= (a_0 + b_0) + (a_1 + b_1)x + (a_2 + b_2)x^2\) \(= (b_0 + a_0) + (b_1 + a_1)x + (b_2 + a_2)x^2\) \(= (b_0 + b_1x + b_2x^2) + (a_0 + a_1x + a_2x^2)\) Using commutativity of real numbers
    🔗
    🔗
    🔗

    (c)

    (A3) \({\mathbf{u}}+ ({\mathbf{v}}+ {\mathbf{w}}) =({\mathbf{u}}+ {\mathbf{v}}) + {\mathbf{w}}\) for all \({\mathbf{u}},{\mathbf{v}}, {\mathbf{w}}\) in \(V\text{.}\)
    🔗
    Solution.
    Let \(w(x) = c_0 + c_1x + c_2x^2\) \([u(x) + v(x)] + w(x)\) \(= [(a_0 + b_0) + (a_1 + b_1)x + (a_2 + b_2)x^2] + (c_0 + c_1x + c_2x^2)\) \(= [(a_0 + b_0) + c_0] + [(a_1 + b_1) + c_1]x + [(a_2 + b_2) + c_2]x^2\) \(= [a_0 + (b_0 + c_0)] + [a_1 + (b_1 + c_1)]x + [a_2 + (b_2 + c_2)]x^2\) \(= u(x) + [v(x) + w(x)]\) Using associativity of real numbers
    🔗
    🔗
    🔗

    (d)

    (A4) There exists an element \({\mathbf{0}}\) in \(V\) such that \({\mathbf{u}}+ {\mathbf{0}}= {\mathbf{0}}+ {\mathbf{u}}={\mathbf{u}}\) for all \({\mathbf{u}}\) in \(V\text{.}\)
    🔗
    Solution.
    Zero polynomial is \(0 + 0x + 0x^2\) For any \(u(x) = a_0 + a_1x + a_2x^2\text{:}\) \({\mathbf{u}}+ {\mathbf{0}}= (a_0 + 0) + (a_1 + 0)x + (a_2 + 0)x^2 = {\mathbf{u}}\)
    🔗
    🔗
    🔗

    (e)

    (A5) For each \({\mathbf{u}}\) in \(V\) there exists an element \(-\bf u\) in \(V\) such that \({\mathbf{u}}+ (- {\mathbf{u}}) = -{\mathbf{u}}+{\mathbf{u}}= {\mathbf{0}}\text{.}\)
    🔗
    Solution.
    For \(u(x) = a_0 + a_1x + a_2x^2\) \(-u(x) = -a_0 - a_1x - a_2x^2\) \(u(x) + (-u(x)) = (a_0 - a_0) + (a_1 - a_1)x + (a_2 - a_2)x^2 = {\mathbf{0}}\)
    🔗
    🔗
    🔗

    (f)

    (S1) If \({\mathbf{u}}\) is in \(V\) and \(r\) is in \(\mathbb{R}\text{,}\) then \(r{\mathbf{u}}\) is in \(V\text{.}\)
    🔗
    Solution.
    For \(u(x) = a_0 + a_1x + a_2x^2\) and scalar \(r\) \(ru(x) = ra_0 + ra_1x + ra_2x^2\) Degree still at most 2, so \(ru(x) \in P_2\)
    🔗
    🔗
    🔗

    (g)

    (S2) \(r ({\mathbf{u}}+ {\mathbf{v}}) =r{\mathbf{u}}+r{\mathbf{v}}\) for all \({\mathbf{u}},{\mathbf{v}}\) in \(V\) and \(r\) in \(\mathbb{R}\text{.}\)
    🔗
    Solution.
    \(r[u(x) + v(x)] = r[(a_0 + b_0) + (a_1 + b_1)x + (a_2 + b_2)x^2]\) \(= r(a_0 + b_0) + r(a_1 + b_1)x + r(a_2 + b_2)x^2\) \(= (ra_0 + rb_0) + (ra_1 + rb_1)x + (ra_2 + rb_2)x^2\) \(= (ra_0 + ra_1x + ra_2x^2) + (rb_0 + rb_1x + rb_2x^2)\) \(= ru(x) + rv(x)\)
    🔗
    🔗
    🔗

    (h)

    (S3) \((r+s) {\mathbf{u}}=r{\mathbf{u}}+s{\mathbf{u}}\) for all \({\mathbf{u}}\) in \(V\) and \(r,s\) in \(\mathbb{R}\text{.}\)
    🔗
    Solution.
    \((r+s)u(x) = (r+s)a_0 + (r+s)a_1x + (r+s)a_2x^2\) \(= (ra_0 + sa_0) + (ra_1 + sa_1)x + (ra_2 + sa_2)x^2\) \(= ru(x) + su(x)\)
    🔗
    🔗
    🔗

    (i)

    (S4) \(r (s {\mathbf{u}}) =(rs) {\mathbf{u}}\) for all \({\mathbf{u}}\) in \(V\) and \(r,s\) in \(\mathbb{R}\text{.}\)
    🔗
    Solution.
    \(r(su(x)) = r(sa_0 + sa_1x + sa_2x^2)\) \(= rsa_0 + rsa_1x + rsa_2x^2\) \(= (rs)u(x)\)
    🔗
    🔗
    🔗

    (j)

    (S5) \(1{\mathbf{u}}={\mathbf{u}}\) for all \({\mathbf{u}}\) in \(V\text{.}\)
    🔗
    Solution.
    \(1u(x) = 1a_0 + 1a_1x + 1a_2x^2 = u(x)\)
    🔗
    🔗
    🔗
    🔗

    Example 4.1.7.

    Let \(V\) be the set of all ordered pairs of real numbers \((x,y)\) with the operations
    \begin{equation*} (x_1,y_1) \oplus (x_2,y_2) = (x_1,0) \text{ and } c\odot(x,y) = (cx,cy). \end{equation*}
    🔗
    Show that \(V\) is not a vector space.
    🔗
    Solution.
    Fails axiom A4: no zero vector exists since \((x_1,y_1) \oplus (x_2,y_2) = (x_1,0)\) always Therefore \(V\) is not a vector space
    🔗
    🔗
    🔗

    Example 4.1.8.

    Let \(V\) be the set of all ordered pairs of real numbers \((x,y)\) with the operations
    \begin{equation*} (x_1,y_1) \oplus (x_2,y_2) = (x_1+x_2,y_1+y_2) \text{ and } c\odot(x,y) = (cx,y). \end{equation*}
    🔗
    Show that \(V\) is not a vector space.
    🔗
    Solution.
    Scalar multiplication fails axiom S3: \((a+b)\odot(x,y) = ((a+b)x,y)\) But \(a\odot(x,y) \oplus b\odot(x,y) = (ax,y) \oplus (bx,y) = (ax+bx,y+y)\) \(((a+b)x,y) \neq (ax+bx,2y)\) Therefore \(V\) is not a vector space
    🔗
    🔗
    🔗

    Example 4.1.9.

    Consider \(V=\) non-negative real numbers, and define vector addition as \({\mathbf{v}}\oplus {\mathbf{u}}=|{\mathbf{v}}-{\mathbf{u}}|\text{,}\) and scalar multiplication as \(a\odot{\mathbf{v}}=|a|{\mathbf{v}}\text{.}\) Does this form a vector space?
    🔗
    Solution.
    The operation is not associative: Let \(x=3\text{,}\) \(y=1\text{,}\) \(z=2\text{.}\) Then: \((x \oplus y) \oplus z = |{|3-1|} - 2| = |2-2| = 0\) But \(x \oplus (y \oplus z) = |3-{|1-2|}| = |3-1| = 2\) Since \((x \oplus y) \oplus z \neq x \oplus (y \oplus z)\text{,}\) axiom A3 (associativity) fails and \(V\) is not a vector space
    🔗
    🔗
    🔗
    Below are some nice facts about the interaction of addition and scalar multiplication with the zero vector and the scalar zero.
    🔗

    Theorem 4.1.10.

    Let \(V\) be a vector space. For any \({\mathbf{u}}\) in \(V\) and \(a\) in \(\mathbb{R}\text{,}\) then
    🔗
    1. \(0 {\mathbf{u}}=\) \({\mathbf{0}}\)
      🔗
      🔗
    2. \(a {\mathbf{0}}=\) \({\mathbf{0}}\)
      🔗
      🔗
    3. If \(a {\mathbf{u}}=\) \({\mathbf{0}}\), then \(a=0\) or \({\mathbf{u}}= {\mathbf{0}}\text{.}\)
      🔗
      🔗
    4. \((-1) {\mathbf{u}}=\) \(-{\mathbf{u}}\)
      🔗
      🔗
    5. \(\displaystyle (-a){\mathbf{u}}=-(a{\mathbf{u}})=a(-{\mathbf{u}}).\)
      🔗
      🔗
